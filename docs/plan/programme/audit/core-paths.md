### 3c. How a path is evaluated end to end

1. Selection: `sweep/selections.py` builds sparse selections (singles, joint sets, samples); `canonical()` drops gated-off forks; `constraints.is_valid` refuses incompatible sets.
2. Run: each selection runs in an isolated process (`runner/worker.py`, `isolation.py`) with METAPHYSICA_VARIANT_<FORK>=option and the build artifacts are written under a fingerprinted directory; fast in-process screening is `runner/screen.evaluate_configuration` with flipped env.
3. Inside the engine, `variants.resolve(fork)` returns forced > METAPHYSICA_SELECTION file > env var > adopted default; an unknown option raises ValueError, a DISABLED option resolves like any other.
4. Verdicts produced: switch_search.evaluate_combination returns `internally_consistent`, `problem_kinds` (CONTRADICTION, ERROR, STRUCTURAL_FAILURE), `blocked_only_by_unevaluable_checks` and a constant VERDICT = "NO_SELECTION_MADE"; testground assessment returns REJECTED / NOT_RUNNABLE / scored configurations and recommendation labels ACTIVE_CONFIRMED, RECOMMEND_CHANGE, DATA_TIEBREAK_SUGGESTS, NO_ADOPTABLE_CONFIGURATION, UNDECIDED; rank.py orders by (consistent, ladder_failed, gates_failed, chi2) and flags `reasonable` (delta chi2 <= 4).
5. Silent fallbacks to the main path: (a) re_t_adoption=computed_vacuum -> 7.086 (-01); (b) g2_closure `_resolved` catch-all (-04); (c) `_metric_construction_adopted` default (-15); (d) forks whose options reach no scored consumer return the default numbers with no warning (-03: 30 of 40 rows); (e) screen.py turns exceptions into UNMEASURED and cache-invalidation errors are dropped (-22, -23); (f) import-cycle literals (-13, -14). fork_reads.json lists b3_origin, moduli_indexing, bulk_signature, face_genericity, metric_construction, twisted_norm_convention as having no counted reads from the build, so choosing their options is not observable in the build.
6. Consequence: the current ranking cannot support a path claim. All 40 rows are inconsistent and the selected row is one of a 29-way tie.
