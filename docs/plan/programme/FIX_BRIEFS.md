# Fix briefs (P2 to P6 execution), 2026-11-11

Inputs: `AUDIT_SUMMARY.md` (clusters, section 4 module verdicts), `audit/<lane>.md` (every finding
with file:line, defect, fix, and a "## Verification" section), `ACTION_SOLUTION_DESIGN.md` (P4).
Each executor round handles at most 15 findings, commits, writes progress and stops.

## Rules for every executor
1. **Ownership is by file.** You fix every finding whose file is in your owned set, whichever
   audit lane reported it: `grep -n "<file name>" docs/plan/programme/audit/*.md`. You edit no
   file outside the set. A fix that needs one goes under "Needs other lane" in your progress file.
2. **Order.** Confirmed critical, confirmed high, partly confirmed (only the part the
   Verification section confirms), then medium and low. Medium and low were never verified: read
   the code first, and if the finding is wrong record `refuted: <reason>`. Skip the refuted ids
   AG-10, CO-24, AB-14, PB-11.
3. **No path-dependent literal.** b3 and b2 come from
   `metaphysica.simulations.PM.geometry.b3_path.seed_values(resolve_path())` (returns `(b3, b2)`);
   n_gen, chi_eff and every other fork choice come from the existing fork readers and
   `metaphysica.simulations.core.variants.resolve(fork_id)`. Another path is tested with
   `variants.selection.forced({...})`. A missing key raises. No `except: pass`, no `or <default>`,
   no reader that answers with the active-path value for an option it cannot evaluate.
4. **Status says what the code does.** Use the status and category vocabulary the registry
   already defines (grep before inventing; a new status is recorded in progress with its
   meaning). A measured value typed in is an input; a value tuned to data is calibrated or
   fitted; an output that restates its input is circular; a value true by construction is an
   identity. Only predictions are scored against data.
5. **Nothing falsified or withdrawn is deleted**, and no fork option is deleted. They stay as
   rows, with their failing numbers. RETIRE-FROM-PAPER means: keep the module and its rows, take
   them out of the paper and out of the score. DELETE applies only to files `AUDIT_SUMMARY.md`
   section 4 lists as dead, after `grep -rn "<module>" src tests` shows no importer and
   `run_all_simulations.py` does not glob the folder.
6. **Text matches the active path.** In every function you touch, units, formula strings,
   comments, docstrings and descriptions are re-read and corrected: bulk 26D (24,2); two 13D
   (12,1) shadows, one time each; 4096-component Weyl spinor; Y_7 = Joyce resolution of
   T^7/(Z2)^3, (b2, b3) = (12, 43); n_gen = b2/4 = 3; chi_eff = 48 n_gen. Text that quotes a
   number is built from the computed value. Before stating a framework result check "Facts that
   must not drift" in `docs/claude-context.md`.
7. **A test per fix**, in a new file `tests/programme/test_<lane>_<topic>.py` (300 lines or
   fewer). Each test must fail on the old code. Edit an existing test only when its subject is a
   file you own and it asserts the defect; say so in progress.
8. **Tests and builds.** Run only the test files you add or touch
   (`PYTHONIOENCODING=utf-8 python -m pytest <files> -q -x`). The full suite takes 86 minutes:
   never run it. Never run `build.py`, `run_all_simulations.py` or any generator that writes
   `AutoGenerated/` or `src/metaphysica/data/`: two other agents work in this tree. A failure
   whose traceback is in a file you do not own: wait two minutes, re-run once, then record it
   under "Downstream" and continue.
9. **Code.** Functions of 60 lines or fewer, new files of 500 lines or fewer, fail early.
   Generic logic goes in a generic module with no PM import; the PM binding stays thin. Do not
   reformat code you are not fixing.
10. **Git.** Never `git add -A`, `commit -a`, stash, reset, checkout, rebase or push. Commit with
    `git add -- <your paths> && git commit -m "<area>: <what>" -- <your paths>` (the path list
    keeps other agents' staged files out). The repo's configured identity is the owner: do not
    change it, and add no attribution or Co-Authored-By line. If `index.lock` exists, wait five
    seconds and retry.
11. **Stop** after 15 findings handled (fixed, refuted or blocked) or when none remain.
12. **Progress** in `docs/plan/programme/progress/<lane>.md`, committed with the code: a table
    `id | file:line | state | commit | test`, then "Downstream" (tests of other lanes that now
    fail, with the reason), "Needs other lane", "Data to confirm", and "Next round" (10 lines
    or fewer).
