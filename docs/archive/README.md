record what was planned and why at the time, and several are now inaccurate —
values, counts and file paths have moved since.

**Do not treat anything here as current.** For the live picture see:

| Roadmap / scaling | [`../FUTURE.md`](../FUTURE.md) |

`visual_baseline/`, which has since moved to `tests/visual_baselines/`;
`TIER_2_3_ROADMAP.md` describes a triple-track migration that has since
landed.
