## Usage

```bash
python -m metaphysica.simulations.visualizations.<module>
```

Plot regeneration is normally driven by `metaphysica-build` (needs the
`[plots]` extra). Outputs land under `AutoGenerated/plots/`.

## Dependencies

- Python 3.9+
- matplotlib, numpy
- (optional) scipy for some advanced visualizations
