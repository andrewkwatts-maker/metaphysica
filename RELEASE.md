# metaphysica release checklist

> **Standing rule**: no AI / LLM / "Generated by …" attribution in any
> commit message, PR body, or release note across any release.

Follow this list in order for every release. Bracket a step as ⏳ before
starting, ✅ when done, ❌ if blocked.

---

## 0. Pre-flight

- [ ] Merge open PRs on `main`; working tree clean.
- [ ] Bump `pyproject.toml`, `rust/physica_core/Cargo.toml`, and
      `src/metaphysica/__init__.py` `__version__` to the target version.
- [ ] Append a fresh `## [<version>] — YYYY-MM-DD` section at the top of
      `CHANGELOG.md` covering every user-visible change.
- [ ] Confirm the standing research-status disclaimer appears at the top
      of `README.md`, `src/metaphysica/website/index.html`,
      `src/metaphysica/__init__.py`, `CHANGELOG.md`, and the paper
      abstract module (`src/metaphysica/simulations/PM/paper/abstract.py`).

## 1. Static hype-language audit

- [ ] `grep -rEn "physics-complete|publication-grade|successfully derives|proves|demonstrates|not tuned|proof-killer|Topologically Frozen"`
      across `README.md`, `CHANGELOG.md`,
      `src/metaphysica/simulations/PM/paper/`,
      `src/metaphysica/website/`.  Expect zero hits or an intentional
      historical annotation only.
- [ ] `grep -rEn "MONAD|PLEROMA|SOPHIA|DEMIURGE|CHRISTOS|BARBELO|ENNOIA|gnostic_name|gnostic_role"`
      across `src/metaphysica/` (excluding the gitignored
      `_gnostic_aliases.py`).  Expect zero hits in committed source.

## 2. Numerology honesty check

- [ ] `proof_completeness_ledger.md` (regenerated) lists the 288/153/135
      split as **fitted decomposition** (not a first-principles
      derivation).
- [ ] CKM Jarlskog surfaces as **phenomenologically tuned** in both
      `ckm_matrix.py` docstring and the paper.
- [ ] PMNS parameters split into **candidate topology-first predictions**
      (θ₁₂, θ₁₃, θ₂₃) vs **fitted / phenomenological inputs** (δ_CP,
      m_base).

## 3. Test suite

- [ ] `python -m pytest tests/ --no-cov -q` — expect ≥1243 pass, 0
      failed (1 known flaky `test_smoke::test_build_callable_exposed`
      unrelated).
- [ ] `python -m pytest tests/test_consistency_beacons.py --no-cov -v` —
      all 10 beacon tests pass, indicating no drift from standard
      physics.

## 4. End-to-end build

- [ ] `rm -rf /tmp/pm_release && mkdir -p /tmp/pm_release`
- [ ] `METAPHYSICA_OUT=/tmp/pm_release python -c "import metaphysica; raise SystemExit(metaphysica.build(out_dir='/tmp/pm_release'))"`
- [ ] Expect 22-24 build steps OK, 0 FAILED.
- [ ] `ls /tmp/pm_release/AutoGenerated/plots/ | wc -l` — expect ≥ 11.
- [ ] PDF page count via `python -c "import PyPDF2; print(len(PyPDF2.PdfReader(open('/tmp/pm_release/AutoGenerated/Principia_Metaphysica_Paper.pdf','rb')).pages))"`
      — expect ≥ 228 pages.
- [ ] `python -c "import json; d=json.load(open('/tmp/pm_release/AutoGenerated/consistency_beacons.json')); print(f\"{d['n_pass']}/{d['count']} beacons pass\")"`
      — expect 8/8.

## 5. Wheel + sdist

- [ ] `cd metaphysica && rm -rf target/wheels/metaphysica-<version>*`
- [ ] `python -m maturin build --release --interpreter python`
- [ ] `python -m maturin sdist`
- [ ] `pip install target/wheels/metaphysica-<version>-*.whl --force-reinstall --no-deps -q`
- [ ] `python -c "import metaphysica; print(metaphysica.__version__)"` — must
      match target version.
- [ ] Smoke-test the unified API: `python -c "import metaphysica; print(metaphysica.GetFloat('b3', kind='constant'))"`
      — must return `24.0`.

## 6. PrincipiaMetaphysica regenerate

- [ ] `cd PrincipiaMetaphysica && python -c "import metaphysica; raise SystemExit(metaphysica.build(out_dir='.'))"`
- [ ] Confirm all changed files are auto-generated (no manual edits
      outside the SOURCE list — see `CLAUDE.md`).
- [ ] Commit + push using `--no-verify` per the pre-commit hook's
      documented regeneration escape hatch:
      `git commit --no-verify -m "Regen from v<version>: <summary>"`

## 7. Zenodo bundle

- [ ] `python scripts/zenodo_pack.py --out ./dist`
- [ ] `unzip -l dist/metaphysica-v<version>-zenodo.zip` — confirm:
       wheel + sdist under `dist/`, `README.md`, `CHANGELOG.md`,
       `LICENSE`, `.zenodo.json`, `CITATION.cff`,
       `principia_metaphysica/AutoGenerated/**`,
       `principia_metaphysica/Pages/**`, `principia_metaphysica/index.html`.

## 8. Tags + GitHub release

- [ ] `cd metaphysica && git tag -a v<version> -m "Release <version>: <one-line summary>"`
- [ ] `git push && git push origin v<version>`
- [ ] `gh release create v<version> --repo andrewkwatts-maker/metaphysica --title "v<version> — <one-line summary>" --notes-file CHANGELOG.md`
      (optional: attach `dist/metaphysica-v<version>-zenodo.zip`).

## 9. PyPI publish (USER-GATED)

- [ ] `twine upload dist/metaphysica-<version>.tar.gz target/wheels/metaphysica-<version>-*.whl`
- [ ] Confirm the release lands at
      https://pypi.org/project/metaphysica/<version>/

## 10. Zenodo upload (USER-GATED, MANUAL)

- [ ] Upload `dist/metaphysica-v<version>-zenodo.zip` at
      https://zenodo.org/deposit/new — Zenodo reads the bundled
      `.zenodo.json` and `CITATION.cff` for metadata.
- [ ] Mint a DOI, then update the paired GitHub repos' README badges to
      point at the new DOI.
